Battle sprites — original artwork only.

Transparent PNGs, one per actor, at the filenames below. Nothing here may be
extracted, captured, or traced from another company's game.

heroes/warden.png, lancer.png, oracle.png, blademage.png, channeler.png,
nullifier.png, monk.png, machinist.png, vanguard.png, brawler.png,
magus.png, thief.png

bosses/blade_tyrant.png, tide_maw.png, ink_lurker.png, crush_wall.png,
storm_keeper.png, spell_weaver.png

Heroes read at roughly 96px tall, bosses at roughly 256px tall, facing the
opposing side of the stage. Hero sprites fall back to a vector silhouette when a
file is absent, so the game stays playable with this folder empty.

Run `npm run art:check` to see what is installed.
