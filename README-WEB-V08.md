# Daily Boss Battle — Playable web UI v0.8

**New:** A responsive, local React frontend for the existing TypeScript battle engine. Choose the v0.6 reference or v0.7 balance candidate; select ready heroes, choose commands, preview effects, and finish a real battle. The battle uses exactly the same reducer as the golden tests.

Read `docs/PLAYABLE-UI-V08.md` for full instructions and boundaries.

Quick start on Windows 11:

```powershell
npm install
npm test
npm run web:build
npm run web:dev
```

Then visit the local URL shown by Vite. No server API or login is required.
